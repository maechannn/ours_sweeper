# サウンド素材一覧

製品版クライアント（`public/index.html`）で使用する音源です。
再生ロジックは `public/index.html` 内の `AUDIO` モジュール（`// AUDIO` セクション）にまとまっています。
音量を変えたいときは同モジュール先頭の `BGM_DEFS` / `SFX_DEFS` の `vol` を編集してください。

## bgm/ — 長尺トラック

| ファイル | 元ファイル名 | 音量 | 再生タイミング |
|---|---|---|---|
| `menu.mp3` | メニュー画面.mp3 | 0.25（小さめ） | **ページを開いた瞬間**から、キャラ選択画面で **Ready!** を押すまで。ループあり。マッチング画面に戻ったときも再開 |
| `ingame.mp3` | ゲームプレイ中_通常.mp3 | 0.25（小さめ） | 5秒カウントダウン終了（ゲーム開始）から試合終了まで。ループあり |
| `drumroll.mp3` | ドラムロール.mp3 | 1.0 | **ループなし**。リザルト演出の2箇所で毎回頭から鳴らす（① グラフの表示開始 ② スコアの表示開始）。曲の**終わり1秒**をかけて音量0までフェードアウトし、そのまま無音 |
| `result.mp3` | リザルト画面.mp3 | 1.0 | 勝敗SE（`victory.mp3` / `defeat.mp3`）が鳴り終わってから、リザルト画面を離れるまで。ループあり。引き分けのみ勝敗SEを挟まず即再生 |

## 自動再生について

メニューBGMはページを開いた瞬間に鳴らそうとしますが、ブラウザの自動再生ポリシーによって
「ユーザーが一度もそのページを操作していない状態」では拒否されることがあります。
拒否された場合は最初のクリックやキー入力を検知して自動的に鳴り出すようにフォールバックしてあります
（`armAutoplayFallback`）。何度か遊んだブラウザでは拒否されなくなり、開いた瞬間から鳴ります。

## 素材を差し替えるとき

同じファイル名で上書きすれば、コードの変更なしで差し替えられます。
ファイル名を変える場合は `public/index.html` の `BGM_DEFS` / `SFX_DEFS` の `src` を合わせて編集してください。

なお実験版（`public-exp/`、`experiment-server.js`）には音を入れていません。
